# Asset Sources and Licenses

## Game assets (`public/assets/`)

All art used by the game (ships, tiles, effects, HUD and menu sprites, spritesheets, vector sources, sounds and the Jungle Gaming logo) comes from the asset pack provided with the challenge statement ([INSTRUCTIONS.md](INSTRUCTIONS.md), section 7) and lives in `public/assets/`.

The repository contains no license file for this pack, and the challenge statement does not state its license terms. Reuse outside this evaluation should be confirmed with the challenge organizer.

## Fonts

No font files are bundled. The interface uses the system font stack declared in `src/index.css` and `src/App.tsx`.

## Code dependencies

Runtime and development dependencies are listed in `package.json` and pinned in `package-lock.json`. Each package is distributed under its own license, available in `node_modules/<package>/` after `npm ci`. `public/mockServiceWorker.js` is generated by MSW (`npx msw init public --save`) with a small local change documented in [README.md](README.md).
